# Heroes Halloween Photobooth

Static HTML/CSS/JS photobooth ready to deploy on Vercel.

- Camera access is requested only when the visitor proceeds to the “Strike your best pose” camera screen. The browser's permission prompt cannot be bypassed.
- Download Photo Strip remains purple (#5D2586).
- Retake All Photos and Choose Another Theme use green (#50B848).
- Orange page background (#F98128), readable text, and existing templates/layout are retained.

Deploy the contents of this folder to your existing Vercel project to update the live site.
